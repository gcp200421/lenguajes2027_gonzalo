1. Box Model

El Box Model define cómo se estructuran los elementos HTML en la página. Está formado por cuatro partes: contenido, padding, border y margin.

2. Propiedad overflow

La propiedad overflow determina qué ocurre cuando el contenido supera el tamaño de su contenedor. Puede utilizar valores como visible, hidden, scroll o auto.

Texto largo que excede los 70px de alto. Gracias a overflow: auto se activa automáticamente la barra de desplazamiento.

3. Propiedad box-sizing

Define cómo se calcula el ancho y alto de un elemento. Con border-box, el padding y el border se incluyen en las dimensiones.

box-sizing: border-box ajusta todo el tamaño sin romper el diseño.

4. Propiedad display

Indica cómo se muestra un elemento en la página. Algunos valores son block, inline e inline-block.

display: block (Fila completa)
display: inline (Fila parcial)
